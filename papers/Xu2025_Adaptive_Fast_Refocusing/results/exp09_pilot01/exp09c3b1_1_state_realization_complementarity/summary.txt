EXP009-C3-B1.1 State + Instantaneous Realization Complementarity
================================================================

Research question
-----------------
Does instantaneous residual evidence contain useful within-state realization information beyond the signal-generated physical state prior?

State-prior construction
------------------------
TRAIN state priors are leave-one-sequence-out cross-fitted. TEST state priors use only TRAIN outcomes. No TEST label enters state construction.

State reproducibility
---------------------
Smooth rho(train state, test utility): 0.929974
Abrupt rho(train state, test utility): 0.899944

Model architecture
------------------
All feature sets use the same two-headed ridge logistic model: pB=P(Beneficial|X), pH=P(Harmful|X), value=pB-pH.
Fixed ridge lambda: 0.100000
